Debris Flow Simulator

Overview

The Debris Flow Simulator is a simplified terrain-based model for observing sediment movement across changing topography.

It is intended for visualisation, design exploration, and comparison of parameter settings. It should not be used for engineering design, hazard prediction, legal analysis, or quantitative forecasting of a real debris-flow event.

Viewer functions

The viewer displays either a procedurally generated alpine terrain or an imported PLY, STL, or OBJ terrain model.

  • OrbitControls: Rotate, zoom, and pan the terrain view.
  • New Terrain: Generates a new procedural alpine terrain.
  • Example Terrain: Loads the example terrain from Kandersteg.
  • Choose 3D Model: Imports a PLY, STL, or OBJ terrain model.
  • Drop 3D Terrain Here: Import a terrain model by dragging it into the drop zone.

Navigation and source placement

  • Shift + left click: Move the release source across the terrain.
  • Cmd / Ctrl + left click: Add points to a custom polygonal release area.
  • Enter: Finish drawing a custom release polygon.
  • Escape: Cancel the current polygon drawing.
  • Backspace: Remove the last polygon point.

Source placement is only available while the simulation is paused.

Terrain representation

The terrain is represented as a regular heightfield. Each horizontal position has one terrain height and one interpolated terrain normal.

This makes collision calculations efficient, but means that overhangs, caves, vertical walls, bridges, and multiple terrain layers are not represented by the physics.

Material and flow

The material model uses macro-particles. Each macro-particle represents a volume parcel rather than a single physical grain.

  • Particle friction: Controls friction between material particles.
  • Kinetic terrain friction: Controls friction between particles and the terrain.
  • Static friction factor: Controls when particles remain at rest on a slope.
  • Particle cohesion: Controls attraction between particles that are separated from their preferred rest distance.
  • Contact damping: Reduces jitter and tangential motion during particle contact.
  • Flow drag length: Controls velocity-dependent drag near the terrain.
  • Start velocity: Defines the initial particle velocity.
  • Simulation speed: Changes the playback speed of the simulation.

Start direction

The initial direction of the material can be controlled using four different modes.

  • Downhill: Starts particles in the direction of the local terrain slope.
  • Fixed heading: Uses a specified horizontal angle.
  • Radial from source: Sends particles away from the source centre.
  • User vector: Uses the specified X and Z vector components.

Erosion and deposition

When terrain evolution is enabled, the terrain can change during the simulation.

  • Fast-moving particles in contact with sufficiently inclined terrain erode a small amount of terrain.
  • Particles that have travelled and later come to rest deposit a small amount of material.
  • Terrain changes are applied periodically rather than after every particle interaction.
  • The process is a visual heightfield approximation and is not a fully mass-conservative sediment budget.

The erosion and deposition rates are expressed as percentages per second. The erosion start speed and deposition speed determine when these processes become active.

Change overlay

The change overlay shows the accumulated history of terrain modification.

  • Blue: Deposition.
  • Red: Erosion.

These colours describe terrain change and not the current particle velocity.

Terrain scale and orientation

  • Model scale: Changes the horizontal scale of the terrain.
  • Metres per model unit: Sets the scale of imported terrain models.
  • Vertical scale: Exaggerates or reduces terrain height.
  • Z axis scale: Changes the terrain depth relative to its width.
  • Rotate X, Y, and Z: Changes the orientation of imported terrain.
  • Reset rotation: Restores the default model orientation.

Source material

The release source can be defined as either a square area or a custom polygon.

  • Release area: Sets the size of a square release zone.
  • Custom polygon: Defines a release zone by drawing points directly on the terrain.
  • Start volume: Defines the total volume of released material.
  • Particles per cubic metre: Controls the number of simulated macro-particles.
  • Add 1000 m³: Increases the source volume by 1,000 cubic metres.

Very large requested particle counts are limited to a maximum of 4,000 simulated particles for performance reasons.

Particle colour modes

  • Velocity: Colours particles according to their current speed.
  • Distance traveled: Colours particles according to their accumulated travel distance.
  • Flow thickness: Estimates local volume per terrain cell.

Particle display scale changes the visual size of the rendered particles without changing their physical volume.

Simulation controls

  • Play: Starts or resumes the simulation.
  • Pause: Pauses the simulation at its current state.
  • Reset: Restores the source, particles, terrain, and simulation time.
  • Simulation cache: Allows previously recorded states to be reviewed with the timeline.

When a cached frame is selected, the simulation enters replay mode. Pressing Play resumes the simulation from the selected frame.

Model limitations

This simulator is not an MPM solver, FLIP solver, PIC solver, SPH solver, or complete DEM solver.

It does not solve pressure, fluid incompressibility, stress tensors, pore-water pressure, angular particle rotation, conservative sediment transport, or complete material constitutive laws.

Gravity, terrain slope, friction, particle contact, cohesion, erosion, and deposition are simplified for visual and exploratory purposes.
